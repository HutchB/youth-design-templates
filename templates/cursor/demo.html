01 — Editor chrome

Fixed heights, hairline panes, zero decoration

The frame is measurable: 36px titlebar and tabs, 24px file rows, 22px mono status bar. Panes are flat fills divided by 1px borders — the layout carries the structure, so color is free to carry meaning.

36 / 24 / 22px

Tab strip, file-tree row and status bar. Three heights, never four.

1px

Every pane divider. No inner shadows, no gradients between columns.

4 / 8 / 12 / 16

The spacing rhythm inside panes. Whitespace belongs to the diff, not the chrome.

02 — Color roles

Graphite floor, orange scalpel, lavender for the agent

Orange is the brand and it is spent carefully: the wordmark and one filled action per view. Lavender means "the model did this". Everything else is graphite, tinted white and muted gray.

primary#f54e00 · one action
accent#c0a8dd · AI stages
raised#26282c · panels, inputs
danger#f87171 · errors, deletions

The canvas never reaches pure black and text never reaches pure white — the graphite / tinted-white pair is what makes the workspace read warm instead of hollow.

03 — AI timeline

Pastels are stage markers, not decoration

Agent progress is told in five pastel chips on one line — thinking, reading, editing, done. They render as low-alpha fills behind matching text, at 10px uppercase, and they appear only inside AI surfaces. Diffs use the same discipline: mint tint for additions, rose tint for deletions, both at roughly a tenth of full strength.

05 — Mobile

The agent becomes the screen

On a phone there is no three-column workspace. The conversation leads, the buffer becomes a preview card you can open, and every hover affordance turns into a tap. Chrome shrinks to a header and an input dock; nothing else survives.
