01 — Blocks over grids

Every command is a card with edges

The classic terminal dumps characters into one scroll; this one groups each command with its output into a raised block — 4px radius, 1px hairline, exit code and duration in the footer. Warm charcoal never turns pure black, and every gray in the system is brown-tinted.

4px

Block radius. Buttons run 3px. The tightest corner vocabulary of any dark dev system here.

#2b2622

The only page tone. Raised blocks sit one warm step above at #383330 — no other background exists.

exit · ms

Every block footer reports its result. The block is a record, not a scroll position.

02 — The off-white voice

Text and buttons share one color

Warm off-white is simultaneously the type color and the only filled button. Display type stays weight 400 — confidence comes from size and tracking, never from bold. There is no chromatic brand accent; amber is not allowed near chrome.

primary#f7f5f0 · text + CTA
surface#2b2622 · warm charcoal
accent#e0a458 · terminal only
danger#fb7185 · failed commands

Buttons are 30px tall with 3px radius and a warm-dark label. A ghost button carries no border until hover.

03 — Terminal semantics

Amber is scoped; green and rose stay inside blocks

Amber marks the terminal's own agency: the AI suggestion bar, running states, slow-test warnings. It never touches buttons, tabs or headings. Success green and error rose are output content — they appear inside blocks and nowhere else.

The suggestion bar is the one dashed border in the system — a soft invitation, not a control. Accepting it promotes the command into a real block.

04 — Completion

The popover is the one place light floats

Completions live in a raised popover above the input block — the only element allowed a large shadow. Its active row gets a subtle off-white wash and an amber left edge; history entries outrank workflow suggestions.

05 — Mobile

One column of blocks and a docked prompt

Panes collapse to a single stream; the agent column becomes a session screen behind a header link. The prompt docks to the bottom like a composer — the off-white run square is the only filled element on the screen.

06 — Off-style, for contrast

What breaks the warmth

neon grid terminal.exe Cool black canvas, magenta glow border, gradient wash, mono display type — the "hacker aesthetic" this system exists to retire. Chromatic accents on chrome are the first sin.
