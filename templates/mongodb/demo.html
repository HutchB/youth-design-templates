01 — Color

Green at full strength or not at all

The bright leaf green belongs to pill buttons and highlight badges, always solid with dark teal text on it. Deep green handles links, active tabs and data marks. The only other saturated colors are the tiny category tags — a fixed, narrow set.

primary#00ed64 · pills, badges
accent#00684a · links, marks
raised#f4f7f6 · wells, headers
ink#001e2b · text, code block
CORE SEARCH Healthy

Category tags stay square-cornered and small — they encode a fixed vocabulary and are the only place purple or orange may appear. Never reuse them as button or link colors.

02 — Structure

Pills for people, rectangles for data

Every interactive button is a full pill at 42px — squaring it breaks the brand signature. Content containers are 12px rounded rectangles, tables sit in 8px frames, and the code block is the one inverted island on the page, floating on a teal-tinted shadow.

Overview Collections Indexes mongosh …

Inputs focus to a 2px deep-green border; rows stay hairline gray. Elevation scales are teal-tinted, not gray, so shadows never turn muddy on white.

03 — Mobile

The console in one thumb column

Cluster cards stack first, the collections table keeps its three most-read columns, and the connect block collapses to a single copyable string. The green pill survives as a full thumb-width action above the tab bar.

04 — Off-style, for contrast

Where enterprise calm breaks

Green wash in a pill box Bright green at 15% as a card fill, text set in deep green, everything rounded to a pill. The signal color becomes wallpaper and the hierarchy disappears.
Same content, on-style White card with a hairline border, ink text, and green reserved for the pill button and status badge. Data marks use deep green; the background never gets tinted.

Also out: squared pill buttons, rounded-off category tags, gray shadows on plain tables, and monospace prose — each one erodes the pragmatic enterprise voice.
