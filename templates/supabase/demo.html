01 — The emerald rule

One green, spent like ink

Emerald marks brand moments: the logo tile, the primary pill, the active nav edge. It always carries deep-green text, never white, and it never becomes a background field. Everything structural is gray hairlines on white.

primary#3ecf8e · brand signal
on-primary#003a1d · text on green
raised#fafafa · headers, nav
accent#7c66a1 · charts only

The violet and chart hues stay inside illustrations. If a color would appear in a pie chart, it does not appear in a toolbar.

02 — The grid

Dense rows, honest data, no chrome

34px

Row height. Header cells share the raised fill; dividers are 1px and nothing else.

12px mono

Ids, timestamps and values run in monospace so columns align by nature, not by padding.

0 shadows

Panels are bordered rectangles. Depth comes from the raised fill one step below white.

A selected row tints green at six percent with a filled checkbox — the loudest a selection is allowed to get.

03 — SQL & mono

Code blocks are the one dark island

On an otherwise light console, SQL inverts to near-black with light text and emerald keywords. The inversion is the signature: when you see the dark block, you are looking at the actual query.

query · users_by_planpostgres 15
select plan, count(*) as n from public.users where status = 'active' -- soft-deleted rows excluded by view group by plan order by n desc;

Inline code stays light: mono at 12–13px on a raised fill with a hairline border — the inversion is reserved for full statements.

04 — Controls

One pill, bordered siblings, quiet ghosts

active pending suspended press / to filter

Only the primary CTA is a pill. Tool buttons stay 30px bordered rectangles; ghost buttons belong in toolbars, never in dialogs.

05 — Mobile

The grid becomes cards, the hairlines stay

Six columns cannot survive a phone, so each row folds into a small bordered card: id and badge on the first line, email on the second, timestamp in muted mono on the third. The language does not change — only the packaging does.

06 — Off-style, for contrast

What breaks the quiet

Green-washed panel 16px radius, emerald at 14% as a field, a green glow shadow, bold green heading. The signal color became wallpaper, and the glow replaced the border.
Same content, on-style 8px radius, white fill, 1px gray border, 13.5px regular text. Green appears once, on the badge, exactly where it means something.
